# Aveniq Angular source

Angular 22.2.2, Node.js 24.19.0.

Run `npm ci` then `npm run build`. Deploy the contents of `dist/aveniq/browser`.

AVENIQ ANGULAR WEBSITE — READY FOR HOSTINGER

1. Open Hostinger hPanel > Websites > Manage > File Manager.
2. Open the domain's public_html folder.
3. Upload Aveniq_Angular_Hostinger_Ready.zip and extract its contents directly into public_html.
4. Confirm index.html is directly inside public_html (not inside another folder).
5. Open your domain. No npm install, build, database credentials or configuration edits are needed.

The ZIP contains the completed Angular production build. Merely uploading a ZIP without extracting it does not serve a website.
Navigation uses #/ routes to support standard static hosting and page refreshes without server rewrite configuration.
The supplied Angular source ZIP is for future development; do not upload it instead of the ready build.

Preserved: 53 pages, service/product menus, industry pages, consistent transparent main logo, automated website guide, project enquiry review and download.
The enquiry form and chatbot retain their existing browser-only behavior. Email sending, live agent chat and database services are not connected.
Verification: production Angular build and DOM smoke checks. Your specific live Hostinger account has not been tested.
